## 1. Web Audio API Synth Engine (⁠･⁠ω⁠･⁠)⁠b

The blog is no longer silent! I integrated a **real-time frequency synth engine** powered by the browser's Web Audio API (zero external MP3 files to load, zero bandwidth overhead!).

* **Dual-Tone Win95 Click**: Every time you click on a nav link, button, or diary entry row, you get a crisp, satisfying mechanical switch sound (⁠>⁠<⁠)
* **Micro-Hover Feedback**: Hovering over post cards or menu items triggers a soft micro-tick frequency.
* **Copy Code Confirmation Beep**: Instant audio confirmation whenever you copy a code snippet!

> (⁠b⁠o⁠_⁠o⁠)⁠b **Privacy & Autoplay Note:** If audio doesn't start immediately, just click anywhere on the page! Modern browsers require a first user interaction to unlock Web Audio playback (⁠^⁠_⁠^⁠)v

---

## 2. Win95 SFX Toggle Button [ SFX ON ] (⁠*⁠^⁠^⁠*⁠)

In the top header menu, I added a classic **Windows 95 3D outset box button**:

* `[ SFX ON ]` — Audio feedback active and responsive!
* `[ SFX MUTE ]` — Mutes all sounds instantly if you prefer total silence during reading.

Your choice is saved automatically in `localStorage` for all your future visits! (⁠★⁠u⁠★⁠)

---

## 3. Top Reading Progress Indicator (⁠ﾉ⁠◕⁠ヮ⁠◕⁠)⁠ﾉ⁠*⁠・ﾟ✧

As you dive into longer diary entries, you'll see a smooth gradient reading progress bar at the very top of your screen that expands as you scroll through the article! (⁠･⁠ω⁠･⁠)⁠b

## 4. Live Log Search & Filter (⁠★⁠u⁠★⁠)

On the [Blog Directory](/blog/) page, I built an instant filter field into the Win95 toolbar!
Type any keyword (title, category, or tag like `React`, `Persona 5`, `Nuremberg`) to filter diary entries in real time across both the Details List and Large Icons view! (⁠/⁠^⁠-⁠^⁠(⁠^⁠^⁠*⁠)⁠/

---

## 5. [ Copy Code ] Buttons for Code Blocks (⁠b⁠o⁠_⁠o⁠)⁠b

All code snippets inside articles now feature a retro `[ Copy Code ]` button in the upper right corner. Clicking copies the snippet to your clipboard, plays the confirmation chime, and displays `[ Copied! ]` for 2 seconds!
